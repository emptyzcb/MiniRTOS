# 嵌入式硬件工程师就业学习流程

这份路线按实际就业来写，目标不是把所有理论都学完，而是尽快具备企业需要的能力：能看懂方案、能画原理图、能画 PCB、能焊板、能调试、能定位问题，并且能把项目讲清楚。

## 1. 岗位目标

嵌入式硬件工程师主要负责：

- 根据需求选择 MCU、传感器、电源芯片、通信芯片等器件。
- 绘制原理图和 PCB。
- 输出 BOM、Gerber、坐标文件，推进打样。
- 焊接、上电、调试硬件。
- 配合嵌入式软件工程师调通外设。
- 定位硬件问题，例如电源异常、通信不通、晶振不起振、复位异常、信号干扰。
- 做基础可靠性和 EMC 设计，例如 ESD、防反接、过流保护、接口保护。

就业重点不是“会背概念”，而是“能不能把一块板子从 0 做到能稳定运行”。

## 2. 第一阶段：电路基础

目标：能看懂常见电路，知道每个元器件为什么放在那里。

需要掌握：

- 电阻、电容、电感的基本作用。
- 二极管、稳压管、TVS 管。
- 三极管、MOS 管的开关用法。
- 上拉、下拉、限流、分压、滤波。
- RC 延时、去耦、电源滤波。
- LED、按键、蜂鸣器、继电器、MOS 驱动。
- 运放、比较器的基础应用。

做到什么程度：

- 能看懂 LED 电路、按键电路、MOS 开关电路。
- 能计算 LED 限流电阻。
- 能判断一个 GPIO 是上拉输入、下拉输入、推挽输出还是开漏输出。
- 能知道电源附近为什么要放 0.1uF 和 10uF 电容。

建议练习：

- 用面包板搭 LED、按键、三极管驱动、MOS 驱动。
- 用万用表测电压、电流、通断。
- 用示波器看按键抖动、PWM 波形、RC 充放电。

## 3. 第二阶段：MCU 最小系统

目标：能独立设计一块 STM32/GD32/ESP32 最小系统板。

需要掌握：

- MCU 供电引脚。
- VDD、VDDA、VSS、VSSA。
- NRST 复位电路。
- BOOT 引脚配置。
- HSE/LSE 晶振电路。
- SWD/JTAG 下载调试接口。
- 串口下载和 USB 转串口。
- 去耦电容布局。

做到什么程度：

- 能根据 datasheet 找到所有电源脚并正确接电。
- 能配置 SWD：SWDIO、SWCLK、GND、3V3、NRST。
- 能画出 STM32 最小系统原理图。
- 能打样后下载程序，点亮 LED，串口输出日志。

第一个项目：

**STM32 最小系统板**

功能建议：

- STM32F103 / STM32H743 / GD32 任意一种 MCU。
- 3.3V LDO 电源。
- SWD 下载口。
- 一个 LED。
- 一个按键。
- 一个串口。
- BOOT 配置。
- 复位按键。

验收标准：

- 上电不短路。
- 3.3V 电压正常。
- SWD 能识别芯片。
- 能下载程序。
- LED 能闪烁。
- 串口能打印信息。

## 4. 第三阶段：常见通信接口

目标：能设计并调通常用外设接口。

需要掌握：

- UART。
- I2C。
- SPI。
- CAN。
- RS485。
- USB 基础。
- 1.8V、3.3V、5V 电平转换。
- 上拉电阻选择。
- 终端电阻。
- TVS 和接口保护。

做到什么程度：

- 能用逻辑分析仪看 UART/I2C/SPI 波形。
- 能判断通信不通是硬件连接、上拉、电平、时序还是软件配置问题。
- 能知道 RS485 为什么需要 A/B 线、终端电阻、TVS。
- 能知道 CAN 为什么要 120 欧终端电阻。

第二个项目：

**传感器采集板**

功能建议：

- STM32 + I2C 温湿度传感器。
- SPI OLED 或 SPI Flash。
- ADC 采样电位器或电池电压。
- UART 输出数据。

验收标准：

- I2C 能扫描到设备地址。
- SPI 能正常显示或读写。
- ADC 数据稳定。
- 串口持续输出传感器数据。
- 能用示波器或逻辑分析仪截图证明通信正常。

## 5. 第四阶段：电源设计

目标：能设计常见板级电源，并知道怎么查问题。

需要掌握：

- LDO。
- Buck 降压。
- Boost 升压。
- 输入保护。
- 防反接。
- 保险丝 / 自恢复保险丝。
- TVS。
- 电源纹波。
- 电源时序。
- 热设计。

做到什么程度：

- 能把 12V/24V 输入转成 5V 和 3.3V。
- 能根据负载电流选 LDO 或 Buck。
- 能看懂电源芯片 datasheet 的典型应用电路。
- 能用示波器测纹波。
- 能判断发热是否异常。

第三个项目：

**24V 工业控制小板**

功能建议：

- 24V 输入。
- 防反接。
- 保险丝。
- TVS。
- Buck 转 5V。
- LDO 转 3.3V。
- STM32 主控。
- RS485 通信。
- MOS 管输出。
- 继电器输出。

验收标准：

- 24V 输入正常工作。
- 5V、3.3V 稳定。
- RS485 能通信。
- MOS 输出能带负载。
- 继电器能吸合释放。
- 短时间运行不异常发热。

## 6. 第五阶段：原理图与 PCB

目标：能完成从原理图到 PCB 打样的完整流程。

建议工具：

- 入门：嘉立创 EDA。
- 就业加分：Altium Designer。
- 开源路线：KiCad。

需要掌握：

- 原理图绘制。
- 封装绘制。
- 元器件选型。
- BOM 整理。
- PCB 布局。
- PCB 布线。
- 铺铜。
- DRC 检查。
- Gerber 导出。
- 坐标文件导出。

PCB 重点：

- 电源线要足够宽。
- 去耦电容靠近芯片电源脚。
- 晶振靠近 MCU，走线短。
- SWD 接口方便调试。
- 大电流和小信号分开。
- 模拟信号远离高频开关电源。
- RS485/CAN/USB 注意阻抗和保护。
- 预留测试点。

做到什么程度：

- 能画 2 层板。
- 能画简单 4 层板。
- 能自己检查封装。
- 能输出打样文件。
- 能根据实际焊接和调试结果修改第二版 PCB。

## 7. 第六阶段：焊接与调试

目标：板子回来后，能自己把它调起来。

需要掌握的工具：

- 万用表。
- 可调电源。
- 示波器。
- 逻辑分析仪。
- 电烙铁。
- 热风枪。
- USB 转串口。
- ST-Link / J-Link。

标准上电流程：

1. 不上电，先目检。
2. 用万用表测 3.3V 和 GND 是否短路。
3. 限流上电。
4. 测输入电压。
5. 测 5V。
6. 测 3.3V。
7. 测 NRST 是否正常。
8. 测晶振是否起振。
9. 连接 SWD。
10. 下载最简单 LED 程序。
11. 调串口。
12. 调外设。
13. 长时间运行观察温度和稳定性。

常见问题定位：

- 上电电流很大：先查短路、芯片方向、电源芯片焊接。
- 没有 3.3V：查输入、电源芯片 EN、反馈电阻、焊接。
- SWD 连不上：查 PA13/PA14、NRST、BOOT、电源、芯片型号。
- 晶振不起振：查负载电容、晶振距离、焊接、时钟配置。
- 串口乱码：查波特率、晶振频率、TX/RX 是否接反。
- I2C 不通：查上拉电阻、地址、电平、SCL/SDA 是否接反。
- RS485 不通：查 A/B、DE/RE、终端电阻、收发方向。

## 8. 第七阶段：可靠性与 EMC 入门

目标：让板子不是“能跑一次”，而是“能稳定跑”。

需要掌握：

- ESD 防护。
- TVS 选型。
- 接口串联电阻。
- 共模电感基础。
- 防反接。
- 过流保护。
- 电源滤波。
- 地线规划。
- 长线通信抗干扰。
- 看门狗。
- 电源掉电和复位异常处理。

做到什么程度：

- 对外接口知道加 TVS。
- 长线接口知道加保护和滤波。
- 大电流输出知道考虑回流路径。
- 电源输入知道考虑浪涌、反接、保险。
- 调试时能用示波器看干扰和电源跌落。

## 9. 简历项目包装

简历上不要只写“学习过 STM32、会 Altium Designer”，要写成项目成果。

推荐写法：

**项目一：STM32 最小系统开发板**

- 使用 STM32 设计最小系统，包括电源、复位、晶振、BOOT、SWD、UART。
- 使用嘉立创 EDA/AD 完成原理图和 PCB。
- 完成打样、焊接、上电调试。
- 通过 SWD 下载程序，实现 LED、按键、串口功能。

**项目二：多传感器采集板**

- 设计 I2C/SPI/ADC 传感器采集电路。
- 使用逻辑分析仪分析 I2C/SPI 通信波形。
- 解决 I2C 上拉和地址冲突问题。
- 实现串口数据输出和采样滤波。

**项目三：24V 工业控制板**

- 设计 24V 输入、电源保护、Buck 降压、RS485 通信、MOS 输出、继电器输出。
- 完成接口 TVS 防护和电源滤波设计。
- 使用示波器测试电源纹波和通信波形。
- 完成硬件调试和第二版 PCB 优化。

## 10. 面试高频问题

硬件基础：

- 电容在电源旁边起什么作用？
- 上拉电阻和下拉电阻有什么区别？
- MOS 管怎么做开关？
- 三极管和 MOS 管有什么区别？
- LDO 和 Buck 怎么选？
- 为什么电源输入要加 TVS？

MCU：

- STM32 最小系统包括哪些部分？
- SWD 下载口需要哪些线？
- BOOT0 有什么作用？
- 晶振不起振怎么查？
- 串口 TX/RX 怎么接？

PCB：

- 去耦电容应该放在哪里？
- 晶振布局要注意什么？
- 电源线为什么要加宽？
- 模拟地和数字地怎么处理？
- 2 层板和 4 层板有什么区别？

调试：

- 板子上电短路怎么查？
- SWD 连不上怎么查？
- I2C 没有 ACK 怎么查？
- RS485 通信失败怎么查？
- 电源纹波大怎么处理？

## 11. 推荐学习顺序

第 1 个月：

- 学电阻、电容、二极管、三极管、MOS 管。
- 学万用表、电烙铁、示波器基础。
- 画简单 LED、按键、MOS 驱动电路。

第 2 个月：

- 学 STM32 最小系统。
- 学嘉立创 EDA 或 Altium Designer。
- 画第一块 STM32 最小系统板。
- 下单打样。

第 3 个月：

- 焊接第一块板。
- 调通电源、SWD、LED、串口。
- 学 UART/I2C/SPI。
- 做传感器采集板。

第 4 个月：

- 学 LDO、Buck、电源保护。
- 学 RS485/CAN。
- 做 24V 工业控制小板。

第 5 个月：

- 整理项目文档。
- 整理原理图、PCB、BOM、调试照片、波形截图。
- 准备面试问题。
- 修改简历。

第 6 个月：

- 投递硬件工程师、嵌入式硬件工程师、助理硬件工程师岗位。
- 根据面试反馈补短板。
- 把项目板迭代第二版。

## 12. 最重要的就业标准

达到下面这些，基本就具备初级嵌入式硬件岗位竞争力：

- 能独立画 STM32 最小系统。
- 能独立画 2 层 PCB。
- 能完成打样、焊接、上电。
- 能用万用表和示波器排查基础问题。
- 能调通 UART/I2C/SPI/RS485 中至少 3 个接口。
- 能设计 5V/3.3V 电源。
- 能看懂 datasheet 的典型应用电路。
- 能讲清楚自己做过的板子怎么设计、怎么调试、哪里出过问题、怎么解决。

硬件工程师最重要的成长方式是：做板、测板、改板。每做一版，你都会比只看课程的人多一层真实经验。
